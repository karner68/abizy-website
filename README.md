# ABA Corporate Page Starter

This is the first design checkpoint for a new ABA corporate-partnership page. It intentionally includes only:

- The existing ABA navigation and routes
- The original corporate-page hero wording
- The ABA logo and group photograph
- A calm navy, red, and white visual treatment
- Restrained entrance and hover effects

The rest of the page will be added one approved section at a time.

## Put it into GitHub

1. Download and unzip `abizy-website-starter.zip`.
2. Open your empty `abizy-website` repository on GitHub.
3. Click **Add file**, then **Upload files**.
4. Drag the *contents* of the unzipped folder into GitHub: `index.html`, `styles.css`, `effects.js`, `README.md`, and the `assets` folder.
5. Click **Commit changes**.

## View it in GitHub Codespaces

1. In the repository, click **Code**.
2. Open the **Codespaces** tab and choose **Create codespace on main**.
3. In the Codespaces terminal, run:

   ```bash
   python3 -m http.server 8000
   ```

4. When Codespaces shows port `8000`, click **Open in Browser**.

## Edit it yourself

- Words and links: `index.html`
- Colors, spacing, sizes, and effects: `styles.css`
- Scrolling behavior: `effects.js`
- Images: `assets/`

Start by reviewing the navigation and hero. Once they feel right, add the next section below the comment in `index.html`.
